# きょうのごはんダイス

食材、調理法、味（土台と足し味）の4つのサイコロを振って、きょうのごはんを決めるWebアプリです。

https://biba-kobo.github.io/gohan-dice/

- 出た目から、料理の例と味つけの目安を出します
- サイコロを押すと、その目を固定できます
- 「だしを使う」をオンにすると、だしを使う料理の例に替わります
- 料理の例から、調味料メーカーや料理教室など作り手のはっきりしたレシピサイトを探せます
- 設定は、使っているスマホの中にだけ保存します
